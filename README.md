# Jogo da Velha

## 🎯 Objetivo do projeto

Este é um projeto simples de **Jogo da Velha (Tic-Tac-Toe)**, feito para praticar os
fundamentos de desenvolvimento web: HTML, CSS e JavaScript puro, sem uso de
frameworks ou bibliotecas externas.

O jogo permite que dois jogadores (X e O) joguem no mesmo computador,
alternando os turnos até que um deles vença ou ocorra um empate.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout responsivo
- **JavaScript (puro/vanilla)** — lógica do jogo

Nenhuma biblioteca ou framework externo foi utilizado.

## 📁 Estrutura das pastas

```text
jogo-da-velha/
│
├── index.html          --> Estrutura principal da página
│
├── css/
│   └── style.css        --> Estilos visuais do jogo
│
├── js/
│   └── script.js         --> Lógica do jogo (regras, turnos, vitória, empate)
│
└── README.md
```

## ▶️ Como executar o projeto

1. Baixe ou clone esta pasta do projeto.
2. Abra o arquivo `index.html` diretamente no seu navegador
   (basta dar dois cliques nele ou arrastar para dentro do navegador).
3. Pronto! O jogo já estará funcionando.

Não é necessário instalar nada nem rodar comandos, pois o projeto é feito
apenas com HTML, CSS e JavaScript puro.

## 🎮 Como jogar

- O jogador **X** sempre começa a partida.
- Clique em uma célula vazia do tabuleiro para marcar sua jogada.
- O turno alterna automaticamente entre X e O.
- O jogo avisa na tela quando houver um vencedor ou um empate.
- Use o botão **"Reiniciar Jogo"** para começar uma nova partida.
